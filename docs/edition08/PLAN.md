## Deliberate choices

The public research product and the private operational repository are separate. Account ownership can change later via configuration. Public repositories can be read/forked; GitHub cannot prevent a stranger proposing a pull request, but only approved maintainers can write and the system will never consume those requests.

The exhibit will use real telemetry. There will be no fabricated audience hidden behind private source. The central model and browser worker play distinct, disclosed roles. The early preview support remains visible until the actual browser workload can sustain itself.
